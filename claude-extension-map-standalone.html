Claude 拡張マップ

Claude を拡張する仕組みは、大きく「道具を足す」「やり方を教える」「まとめて配る」の3つに分かれます。サブエージェント・フック・CLAUDE.md は主に Claude Code 側の仕組みで、この3つの間に入ります。

まず3つの役割

コネクタ（MCP）道具を足す。外部のサービスやデータに Claude が触れるようにする。中身は MCP サーバーへの接続。
スキルやり方を教える。手順・書式・チェックリストを書いたファイル（必要ならスクリプト付き）。依頼に合ったときだけ読まれる。
プラグインまとめて配る箱。スキル・コネクタ・コマンド・サブエージェント・フックを1回のインストールで入れる。

1つの依頼がどこを通るか

入れた場所によって、使える場所が変わる

それぞれの違い

仕組み何を足すかいつ読まれる・動くかこのリポジトリでの例
コネクタ（MCP）プラグイン可外部サービスへのアクセス（道具）接続しておき、Claude が必要なツールを呼ぶdashboard-db-ro（DB の読み取り）、Claude Docs
スキルプラグイン可手順・書式・チェックリスト（やり方）説明文は毎ターン、本文は依頼に合ったときだけ。/名前 でも呼べる/deploy・/schema-change・/backup-ops
コマンドプラグイン可名前で呼ぶ操作Claude Code ではスキルに統合済み（.claude/commands/ も引き続き動く）—
サブエージェントプラグイン可作業を任せる別の担当Claude が委任し、別のコンテキストで作業して結果だけ返すExplore・Plan
フックプラグイン可決まった時点で必ず動くコマンドツール実行の前後など。Claude の判断を介さない—
CLAUDE.md毎回守らせる事実・規約毎ターン全文このリポジトリの CLAUDE.md
組み込みツール最初からある道具Claude が呼ぶ。許可は権限設定で決まるRead・Edit・Bash・Web検索
プラグイン上の「プラグイン可」をまとめた箱有効な間、中身のスキルやエージェントの説明文が毎ターン載るanthropic-skills:pdf など、名前に プラグイン名: が付いたスキル

ローカルで動くコネクタ（デスクトップ拡張・.mcpb）はデスクトップアプリ用です。Claude Code では、ローカルの MCP サーバーを claude mcp add で直接登録します。
